# Ручная проверка полного маршрута

Этот тест выполняется после запуска PostgreSQL и Spring, перед началом исправления ошибок этапа 6. На первую проверку потребуется примерно 25–40 минут.

## 1. Запуск сервера

Из каталога проекта:

```bash
cd Kotlin_spring_project
cp -n .env.example .env
```

Откройте `.env` и задайте локальный `IVR_DB_PASSWORD`. Затем:

```bash
set -a
source .env
set +a
docker compose up -d --wait db
./gradlew test
./gradlew bootRun --args='--spring.profiles.active=local'
```

Сервер готов к ручной проверке после сообщения о запуске на порту `8080`. Окно терминала с `bootRun` оставьте открытым.

## 2. Запуск Unity

1. Откройте каталог `Unity_WEB_A_IVR` в Unity Hub.
2. Используйте Unity `6000.4.1f1`.
3. Откройте `Assets/Scenes/Main.unity`.
4. Нажмите Play.
5. Откройте Console и очистите старые сообщения перед тестом.

## 3. Чек-лист

Используйте новый уникальный email, например `test+дата-время@example.com`.

| № | Действие | Ожидаемый результат |
| --- | --- | --- |
| 5.1 | Запустить `Main` без сохранённой сессии | Открывается стартовый экран, элементы Unity по умолчанию не видны |
| 5.2 | Открыть регистрацию и отправить пустую форму | Появляется понятная ошибка, запрос не отправляется |
| 5.3 | Ввести разные пароли | Форма сообщает о несовпадении |
| 5.4 | Зарегистрировать новый email | Открывается онбординг, в Console нет исключения |
| 5.5 | Пройти информационные шаги и сохранить интересы | Запускается диагностический квиз |
| 5.6 | Ответить на диагностические вопросы | После каждого ответа видны подсветка и объяснение; двойной клик не меняет ответ |
| 5.7 | Завершить диагностику | Показан результат, затем главное меню; очки начислены один раз |
| 5.8 | Открыть «Твои уроки» | Видна персональная карточка с разбором, примером и шпаргалкой |
| 5.9 | Запустить повторный тест из карточки | Открывается квиз соответствующей темы |
| 5.10 | Набрать не менее 50% | После возврата урок отмечен как закреплённый |
| 5.11 | Запустить обычный тест из базовой темы | Вопросы относятся к теме, результат сохраняется |

| 5.19 | Запустить Spring повторно и повторить действие | Клиент снова использует сервер |

## 4. Как передать результат

Для каждого сбоя пришлите:

```text
Шаг: 5.8
Ожидалось: появилась персональная карточка
Получилось: список пустой
Unity Console: первая красная ошибка целиком
Spring: последние 20–30 строк после запроса
```

Пароль, JWT и содержимое `.env` присылать не нужно. Если шаг прошёл, достаточно написать `5.1–5.7 OK`. Исправление этапа 6 начинается после первого полного прохода и списка неудачных шагов.

## 5. Завершение проверки

Остановите Spring сочетанием `Ctrl+C`, затем:

```bash
docker compose down
```

Данные остаются в Docker volume для проверки повторного входа. Для полностью чистого теста данные следует очищать отдельно только после сохранения результатов проверки.
