Этот каталог содержит материалы для оценки проектирования ИТ-продукта. Диаграммы описывают текущий код Unity и Spring Boot; будущие функции в них не включены.

- [Пользовательские сценарии](USER_SCENARIOS.md) — предусловия, основной поток, исключения и результат.
- [Use Case](diagrams/USE_CASE.md) — роли и доступные им действия.
- [Компоненты и классы](diagrams/CLASSES.md) — границы системы и ключевые зависимости Unity/Spring.
- [Диаграммы последовательностей](diagrams/SEQUENCES.md) — регистрация, квиз, персональный урок и биржевая операция.
- [Модель данных](diagrams/DATA_MODEL.md) — ER- и объектная диаграммы.

Исходный пользовательский маршрут верхнего уровня также приведён в [`ARCHITECTURE.md`](../ARCHITECTURE.md).
