**Целевая аудитория:** школьники, студенты и начинающие специалисты 14–22 лет

## Проблемное поле

Молодые пользователи сталкиваются с финансовыми решениями до появления системного опыта управления личными деньгами. Обычные справочные материалы не всегда дают немедленную обратную связь и не показывают последствия выбора. Из-за этого финансовые темы могут восприниматься как сложные, оторванные от практики и недостаточно вовлекающие.

Команда проводила опросы представителей целевой аудитории и использовала их общие результаты при формировании концепции. Исходные анкеты и сводные таблицы не включены в репозиторий, поэтому точные количественные показатели не приводятся. Дополнительно были изучены открытые материалы Банка России и существующие образовательные продукты.

Проект решает проблему через короткий игровой маршрут: диагностику знаний, объяснение слабой темы, повторную проверку, ежедневные задания и моделирование финансовых операций на учебном рынке.

## Заказчик и целевая аудитория

Заказчиком выступает АО «Альфа-Банк». Техническое задание согласовано представителем заказчика; подписанный лист размещён в `docs/final/customer_signed_technical_assignment.pdf`.

Основные группы пользователей:

1. Старшеклассники, которым нужны понятные бытовые примеры и базовые финансовые понятия.
2. Студенты, начинающие самостоятельно управлять бюджетом и пользоваться финансовыми продуктами.
3. Начинающие специалисты, которым полезны темы накоплений, кредитов, страхования и инвестиций.

## Образ продукта

Продукт представляет собой браузерную обучающую игру на Unity WebGL с сервером Kotlin/Spring Boot и PostgreSQL. Пользователь создаёт учётную запись, проходит приветствие и диагностику, получает персональный материал по слабой теме, повторяет её, выполняет ежедневные задания, играет в мини-игру и использует учебный рынок. Критические действия проверяются сервером, а прогресс сохраняется в базе данных.

## Функциональные требования

1. Регистрация, вход, выход и восстановление сохранённой сессии.
2. Пятиэкранное приветствие и сохранение интересов пользователя.
3. Диагностический тест по всем доступным финансовым темам.
4. Серверная проверка ответов, сохранение попыток и расчёт результата.
5. Базовые уроки и тематические тесты с объяснением ответов.
6. Определение слабой темы и формирование персонального разбора.
7. Резервный учебный материал при недоступности FinStory.
8. Сохранение прогресса, очков и истории серверных действий пользователя.
9. Ежедневная серия, ежедневные задания, коины и награды.
10. Каталог мини-игр и работающая мини-игра «Офис мечты».
11. Учебный рынок с операциями BUY, SELL, SHORT и COVER.
12. Портфель пользователя и рейтинг по стоимости виртуального капитала.
13. Энциклопедия тем с отображением учебного прогресса.
14. Профиль пользователя с возможностью повторно открыть приветствие.
15. Административная панель для управления демонстрационным состоянием.

## Аппаратные и программные требования

Для локального запуска требуются Windows 10/11, Docker Desktop, JDK 21, современный браузер и Unity 6000.4.6f1 с модулем Web Build Support. Серверные сервисы запускаются в Docker Compose или локально через Gradle. Для постоянной публичной работы потребуются удалённый сервер, домен, HTTPS и безопасное хранение секретов.

## Инструменты разработки и база данных

- Unity 6000.4.6f1, C# и UI Toolkit — клиентский интерфейс и игровая логика;
- Kotlin, Spring Boot 4.1 и Java 21 — REST API и серверные правила;
- PostgreSQL 16, Spring Data JPA и Flyway — долговременное состояние и миграции;
- Python — сервис FinStory и резервная обработка персональных материалов;
- Docker Compose — локальное совместное выполнение сервисов;
- GitHub Actions — тестирование и сборка контейнеров;
- H2 — изолированные серверные тесты.

PostgreSQL хранит пользователей, попытки, ответы, персональные уроки, прогресс, задания, награды и операции учебного рынка. Пароли хранятся в виде BCrypt-хэшей, а защищённые запросы используют JWT.

## Аналоги

Портал «Финансовая культура» Банка России предоставляет статьи, калькуляторы, тесты и веб-игры. Всероссийский онлайн-зачёт проверяет знания и формирует рекомендации по ошибкам. Проект «Финтрек» сочетает уроки, задания и достижения. Alfa IVR Financial Game отличается объединением диагностики, персонального разбора, ежедневной активности, мини-игры и учебного рынка в одном сохраняемом пользовательском маршруте.

1. Исследование аудитории и проблемного поля, анализ открытых источников и опросов.
2. Изучение аналогов и формирование концепции игрового обучения.

4. Создание Unity-клиента, Spring API и структуры PostgreSQL.

Значительная часть разработки выполнялась локально и затем отправлялась в GitHub крупными обновлениями, поэтому даты коммитов не являются точным календарём выполнения отдельных задач.

## Возможные риски

1. **Недостаточная проверка потребностей аудитории.** Снижается дополнительными пользовательскими тестами готового прототипа и фиксацией результатов.
2. **Переусложнение механик.** Снижается приоритизацией сквозного MVP и поэтапным добавлением функций.
3. **Несовместимость компонентов.** Снижается единым REST-контрактом, согласованием JSON-форматов и интеграционными тестами.
4. **Сетевые ошибки и недоступность внешних сервисов.** Снижается понятными сообщениями, сохранением состояния и резервными материалами.
5. **Риски публичного развёртывания.** До появления HTTPS, мониторинга и защищённого хранения секретов продукт демонстрируется локально.

## Состояние итоговой версии

Подтверждение почты и восстановление пароля перенесены в дальнейшее развитие. Все изменения относительно первоначальной концепции перечислены в `changes.md`.
